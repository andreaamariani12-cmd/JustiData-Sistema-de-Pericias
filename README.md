# JustiData – Sistema de Gestión y Seguimiento de Pericias

Trabajo Práctico Anual 2026 de **Ingeniería de Software I** (FCyT – UADER)

## Descripción

Prototipo de interfaz HTML para el sistema de gestión y seguimiento de pericias judiciales de la empresa ficticia **JustiData Solutions S.A.**. El sistema contempla pericias médicas, psicológicas, informáticas, contables, accidentológicas y documentológicas.

## Funcionalidades del prototipo

- **Carga de nuevo informe pericial:** formulario para registrar un informe nuevo.
- **Búsqueda de informes:** pantalla para buscar informes existentes.
- **Visualización de informe por pantalla:** detalle completo de un informe.
- **Estructura general:** encabezado, menú de navegación, pie de página y datos de sesión.
- **Diseño responsive:** se adapta a PC y a dispositivos móviles.

## Cómo ver el proyecto

1. Descargá el repositorio (**Code → Download ZIP**) o clonalo:
   ```bash
   git clone https://github.com/andreaamariani12-cmd/JustiData-Sistema-de-Pericias.git
   ```
2. Abrí el archivo `index.html` con cualquier navegador.
